# HR Analytics Dashboard | Power BI

## Project Overview
The HR Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI. It analyzes employee data to understand workforce distribution, employee attrition, job satisfaction, and other HR-related metrics.

## Objectives
- Monitor total and active employees.
- Analyze employee attrition and attrition rate.
- Explore attrition patterns across departments and salary slabs.
- Examine the relationship between job roles and job satisfaction.
- Understand workforce distribution by age group and gender.
- Analyze attrition trends by employee experience.

## Key Performance Indicators (KPIs)
- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Experience

## Tools and Technologies
- Microsoft Power BI — dashboard development and visualization
- Power Query — data transformation, if used
- DAX — calculations and measures, if used
- HR employee dataset — source data for analysis

## Project Highlights
- Interactive HR dashboard with KPI cards.
- Department-wise and demographic analysis.
- Attrition analysis by salary slab and job role.
- Visual analysis of employee experience and satisfaction.
